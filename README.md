# 🌸 Bouquet Box Flower Bar – Landing Page

Welcome to the **Bouquet Box Flower Bar** landing page!  
This project is a fully responsive, stylish HTML/CSS-based website that promotes a luxury floral event experience. It features a modern layout, mobile responsiveness, and integrated social media icons.

## 🚀 Features

- Responsive navigation bar with logo and menu
- Two-column hero section with image and text
- Custom buttons and hover effects
- Footer with newsletter subscription input
- Social media icons
- Clean and modern design

## 🛠️ Tech Stack

- HTML5
- CSS3
- Font Awesome (via CDN)
- Responsive design with media queries
